# 한일 국제교류 수업 자료집 (전자책)

공도초등학교 「한일 국제교류 수업 자료집」 원본 64쪽을 그대로 보여 주는 정적 웹 전자책입니다.

- `index.html` : 전자책 뷰어 (한쪽/양쪽 보기, 확대·축소, 목차 이동)
- `pages/p-01.webp` ~ `p-64.webp` : 원본 쪽 이미지 (가로 2400px)
- `vercel.json` : Vercel 설정

## 배포 (GitHub → Vercel)
1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. vercel.com → Add New → Project → 저장소 Import
3. Framework Preset: Other, Build Command / Output Directory: 비워 두고 Deploy
